# เว็บไซต์แนะนำ บริษัท พีบี วัลเล่ย์ เชียงราย (PB Valley Chiang Rai)

เว็บไซต์นำเสนอและแนะนำธุรกิจแบบ One-Page Responsive ออกแบบด้วยธีมเกษตรกรรมประณีต โทนสีโกโก้เข้ม ผสานทองอำพันและสีเขียวธรรมชาติของขุนเขาเชียงราย

---

## 📂 โครงสร้างเว็บไซต์และ 3 ส่วนหลัก

1. **ส่วนที่ 1: แนะนำบริษัท (Company Overview)**
   - ความเป็นมา วิสัยทัศน์ และปณิธานการพัฒนาเกษตรกรรมยั่งยืนในจังหวัดเชียงราย
   - จุดติดตั้งคลิปวิดีโอแนะนำบริษัท (`Video Slot #1`)

2. **ส่วนที่ 2: สวนโกโก้ (Cocoa Plantation)**
   - สภาพภูมิอากาศ ภูมิทัศน์เชียงราย ดินภูเขา และการปลูกแบบวนเกษตร (Agroforestry)
   - การคัดสายพันธุ์คุณภาพ และการเก็บเกี่ยวผลสุกด้วยมือ
   - จุดติดตั้งคลิปวิดีโอพาชมสวนโกโก้ (`Video Slot #2`)

3. **ส่วนที่ 3: การแปรรูปโกโก้ (Cocoa Processing & Bean-to-Bar Craft)**
   - 5 ขั้นตอนการแปรรูป: แกะเมล็ด, หมักบ่ม 5-7 วัน, ตากแดดธรรมชาติ, คั่วแบบประณีต, บดและนวดเนื้อ
   - ผลิตภัณฑ์เด่น: คราฟต์ช็อกโกแลต, ผงโกโก้แท้ 100%, โกโก้นิบส์, ชาเปลือกโกโก้
   - จุดติดตั้งคลิปวิดีโอพาชมโรงเรือนและการแปรรูป (`Video Slot #3`)

## 🎬 วิธีการนำคลิปวิดีโอมาใส่

เว็บไซต์นี้ถูกเตรียมพร้อมให้ท่านนำคลิปมาใส่ได้ง่ายมาก โดยเลือกทำได้ **2 วิธี**:

### วิธีที่ 1: ทำผ่านหน้าเว็บได้ทันที (สะดวกที่สุด ไม่ต้องแก้โค้ด)
1. เปิดไฟล์ `index.html` บนเบราว์เซอร์ (Chrome, Edge ฯลฯ)
2. คลิกปุ่ม **"⚙️ ตั้งค่าวิดีโอ / ใส่คลิป"** ที่แถบเมนูด้านบนขวา
3. จะมีหน้าต่างขึ้นมาให้ท่านระบุคลิปทั้ง 3 ส่วน:
   - **กรณีใช้ YouTube:** วางลิงก์ YouTube ได้เลย เช่น `https://www.youtube.com/watch?v=xxxxxx`
   - **กรณีใช้ไฟล์วิดีโอ:** วางไฟล์ `.mp4` ในโฟลเดอร์ `videos/` แล้วพิมพ์ เช่น `videos/company-intro.mp4`
4. กดปุ่ม **"บันทึกและแสดงผล"** วิดีโอจะเล่นบนหน้าเว็บทันที (ระบบจะจำค่าไว้ในเบราว์เซอร์)

---

### วิธีที่ 2: แก้ไขในโค้ด `index.html` โดยตรง

ในไฟล์ `index.html` มีการระบุตำแหน่งไว้ชัดเจน โดยท่านสามารถแทนที่ส่วน `<div class="media-target">` ในแต่ละช่องได้ดังนี้:

#### สำหรับไฟล์วิดีโอในเครื่อง (.mp4):
นำไฟล์ไปวางในโฟลเดอร์ `videos/` เช่น `videos/company-intro.mp4` แล้วใส่โค้ด:
```html
<video controls class="w-full h-full object-cover">
  <source src="videos/company-intro.mp4" type="video/mp4">
</video>
```

#### สำหรับลิงก์ YouTube:
```html
<iframe 
  src="https://www.youtube.com/embed/รหัสวิดีโอYouTube?rel=0" 
  title="PB Valley Video" 
  allowfullscreen 
  class="w-full h-full">
</iframe>
```

## 🚀 วิธีเปิดใช้งาน
- **เปิดทันที:** ดับเบิลคลิกเปิดไฟล์ `index.html` ในโฟลเดอร์ `d:\ทำเว็ป\` ได้ทันที
- **หรือเปิดด้วย Local Web Server (ถ้าต้องการ):**
  ```powershell
  cd "d:\ทำเว็ป"
  python -m http.server 8000
  # จากนั้นเปิดเบราว์เซอร์ไปที่ http://localhost:8000
  ```

# PB Valley Chiang Rai

เว็บไซต์แนะนำบริษัทแบบหน้าเดียว รองรับภาษาไทย–อังกฤษและหน้าจอมือถือ ใช้ HTML, CSS และ JavaScript โดยไม่มีขั้นตอน build

## ตำแหน่งโปรเจกต์

ไฟล์หลักอยู่ที่ `D:\pb-valley-chiangrai-web` ให้เลือกโฟลเดอร์นี้เป็นพื้นที่ทำงานในแอป โฟลเดอร์ย่อย `ทำเว็ป` ว่างและไม่ได้ใช้กับเว็บ

## การเปิดเว็บ

- ดับเบิลคลิก `เปิดเว็บ.bat` เพื่อเปิดเว็บผ่านเซิร์ฟเวอร์ localhost พอร์ต 8080–8090 เปิดหน้าต่างไว้ระหว่างใช้งาน และปิดเมื่อต้องการหยุด
- เปิด `index.html` โดยตรงได้ แต่สื่อภายนอกบางชนิดอาจทำงานต่างจากการเปิดผ่าน HTTP
- เปิด `mobile-preview.html` บนคอมเพื่อดูเว็บในกรอบขนาดมือถือหรือแท็บเล็ต เลือกขนาดและรีเฟรชได้ หากใช้เซิร์ฟเวอร์ ให้เปิด `/mobile-preview.html` บนพอร์ตเดียวกัน
- หน้าตัวอย่างจำลองขนาดหน้าจอ ไม่ได้จำลองระบบสัมผัสหรือเบราว์เซอร์ของโทรศัพท์ทั้งหมด

## ไฟล์หลัก

- `index.html`: เนื้อหาหน้าเว็บ เมนู ส่วนแนะนำบริษัท สวนโกโก้ การแปรรูป สินค้า และติดต่อ
- `css/style.css`: ธีมสี รูปแบบหน้าจอและแอนิเมชัน
- `js/main.js`: เมนูมือถือ สไลด์รูป สถานะร้าน สภาพอากาศ การเปลี่ยนภาษา และแถบสินค้า
- `js/translations.js`: ข้อความภาษาไทย–อังกฤษ ภาษาเลือกถูกบันทึกในเบราว์เซอร์
- `Stock/`: รูปสินค้าจริง ส่วน `img/`, `logo/`, `videos/` เป็นสื่อประกอบ
- `mobile-preview.html`: หน้าดูตัวอย่างขนาดมือถือบนคอม
- `server.ps1`, `เปิดเว็บ.bat`: เซิร์ฟเวอร์สำหรับเปิดเว็บในเครื่อง

## สินค้า

แถบสินค้าอยู่ระหว่างส่วนการแปรรูปกับส่วนติดต่อ หัวข้ออยู่ตรงกลางและขอบตรงกับเนื้อหาด้านบน รูปเลื่อนวนอัตโนมัติ หยุดระหว่างลากหรือใช้ล้อเมาส์ แล้วเลื่อนต่อ มีปุ่มก่อนหน้า ถัดไป และหยุด/เล่น

รายชื่อรูปถูกระบุใน `index.html` ไม่ได้อ่านโฟลเดอร์อัตโนมัติ หากเพิ่ม ลบ หรือเปลี่ยนชื่อไฟล์ ให้ปรับ `src` ในแถบสินค้าทั้งสองชุด และปรับข้อความ `gallery.stock*.title` ใน `js/translations.js` ให้ตรงกัน

รูปขนมสองไฟล์ยังใช้ชื่อไฟล์ต่างกัน (`อัดเม็ด` และ `อัดเมล็ด`) แต่ชื่อที่แสดงบนเว็บแก้เป็น “ลูกอมโกโก้อัดเม็ด” ทั้งคู่แล้ว

## วิดีโอ

ส่วนสวนโกโก้มีวิดีโอ YouTube แล้ว ส่วนแนะนำบริษัทและการแปรรูปยังไม่มีคลิป และแสดงข้อความวิดีโอเร็ว ๆ นี้ ไม่มีหน้าตั้งค่าวิดีโอในเว็บปัจจุบัน

เมื่อต้องการเพิ่มคลิป ให้แทน `.video-placeholder` ภายใน `#video-player-1` หรือ `#video-player-3` ด้วย `<video controls>` ที่อ้างไฟล์ใน `videos/` หรือ iframe YouTube ที่มี title, allowfullscreen และ referrerpolicy อย่าลบกรอบ `.video-wrapper`
